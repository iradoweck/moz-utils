# moz-utils Website & Documentation Portal

This directory contains the official website, interactive documentation, and web-based simulators for the **moz-utils** ecosystem.

## Overview

The website is a React Single Page Application (SPA) powered by Vite. It serves as the central hub for developers integrating `moz-utils` into their projects.

Key features include:
- **Interactive Documentation**: Comprehensive guides on using `moz-utils` for Identity, Finance, and Geography.
- **Unified Simulator**: A central test center to validate NUITs, BIs, Phone Numbers, and CEPs in real-time.
- **Insights Dashboard**: Live metrics from NPM, PyPI, Packagist, Pub.dev, and GitHub.
- **Seamless Internationalization (i18n)**: Fully translated into English and Portuguese, featuring fluid global cross-fade transitions without layout shifts.

## Running Locally

To run the website locally during development:

```bash
cd website
npm install
npm run dev
```

## Deployment

The website is automatically deployed to GitHub Pages via the `.github/workflows/deploy-website.yml` action. It uses HashRouter to prevent 404 errors natively generated by GitHub Pages SPA routing.
